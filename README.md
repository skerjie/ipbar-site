# IPBar

Your public IP address in the macOS menu bar: where it points, who provides it,
your local address, IPv6 when you have it, and the latency to a host you pick.
Click any value to copy it.

**[Download the latest version](https://github.com/skerjie/ipbar-site/releases/latest)**
· macOS 14 or later · signed and notarized by Apple

IPBar collects nothing. The [privacy policy](PRIVACY.md) ([по-русски](PRIVACY.ru.md))
lists every service it talks to and what each one receives.

Questions and bug reports: [issues](https://github.com/skerjie/ipbar-site/issues).

# IPBar по-русски

Ваш публичный IP-адрес в строке меню macOS: где он, чей он, ваш локальный
адрес, IPv6, если он есть, и задержка до выбранного хоста. Любое значение
копируется кликом.

**[Скачать последнюю версию](https://github.com/skerjie/ipbar-site/releases/latest)**
· macOS 14 и новее · подписано и нотаризовано Apple

IPBar ничего не собирает. В [политике конфиденциальности](PRIVACY.ru.md)
перечислены все сервисы, к которым он обращается, и что каждый из них получает.

Вопросы и ошибки — в [issues](https://github.com/skerjie/ipbar-site/issues).
